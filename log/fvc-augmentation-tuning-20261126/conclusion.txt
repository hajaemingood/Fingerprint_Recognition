FVC 원본 증강과 투영층 조정
2026-11-26

기존 FVC 240장을 사용했다. DB당 기존 확인 ID 3개를 잠그고 나머지 7개를
학습 4개와 검증 3개로 나누는 분할을 3회 구성했다. 원본과 증강본은 같은 ID로 관리했다.
기준 DLL·ONNX의 해시가 직전 실험과 일치하여 기존 KISA 9,480쌍 기준 기록을 재사용했다.

배포 전처리를 적용하기 전에 원본 픽셀에 증강을 수행했다. 증강당 개발 영상별로 시드 고정 변형 1개를
생성했고, 각 학습 배치에 원본과 해당 증강 입력을 50:50으로 넣었다. 검증과 확인은 원본 TIFF로만 수행했다.
증강 방식은 회전 ±5°와 이동 ±3%, 밝기 ±10과 대비 0.9~1.1, 위치와 명암 조합, 가우시안 σ=2~5였다.

원본으로 12·48·120스텝, 학습률 3e-5·1e-4를 비교했다. 고정 22:78에서 48스텝·3e-5를 선택했다.
다섯 증강군의 세 분할 평균 EER은 모두 2.21% / 3.89% / 9.16%였다. 원본과 증강의 활성값은 달랐다.
질감만·특징점만·양쪽, rank 4·8, 반영률 25%·50%·100%, 무작위 타인 쌍 혼합, SupCon을 평가했다.
FVC2002의 세 분할 평균 EER은 이 과정에서 기존 3.89%보다 낮아지지 않았다.
미학습 ID에서 투영층 개선을 재현하지 못해 합성곱층 추가 학습 조건을 충족하지 않았다.

고정 22:78 검증 상위의 투영층 후보 3개와 기준 모델에서 질감 비중을 0~100%로 탐색했다.
평균 EER이 가장 높은 DB의 EER을 우선 최소화했다. 원본 48스텝·학습률 3e-5·양쪽 선형층
직접 갱신·트리플릿·반영률 100%의 후보와 공통 85:15 비율이 선택됐다. 기준 모델도 85:15가 선택됐다.
후보 선택 뒤 확인 ID를 제외한 7개 ID 전체로 투영층을 재학습했다.

조건              전체 EER FVC00 / FVC02 / FVC04      확인 EER FVC00 / FVC02 / FVC04
기준 22:78                   2.64 / 6.48 / 4.78%                  1.38 / 11.68 / 4.72%
기준 85:15                   2.89 / 9.00 / 5.79%                  0.00 / 16.93 / 7.81%
후보 22:78                   2.64 / 6.46 / 4.75%                  1.38 / 11.68 / 4.72%
후보 85:15                   2.89 / 8.98 / 5.79%                  0.00 / 16.93 / 7.81%

전체는 DB당 3,160쌍, 확인은 DB당 276쌍이다. 85:15 후보를 별도 ONNX와 C++ DLL로 내보냈다.
KISA 9,480쌍에서 처리 실패가 없었다. ONNX와 C++ 점수는 FVC2002 2쌍만 0.001 차이가 있었고 EER은 모두 같았다.
세 DB EER 3% 이하 목표는 미달이며, build/evaluator의 배포 DLL·ONNX는 이번 실험 전과 같다.
