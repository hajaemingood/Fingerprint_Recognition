FVC2002·FVC2004 노이즈 및 DeepPrint 미세조정 실험
2026-11-24

실험 조건

가우시안 노이즈는 8비트 영상에서 표준편차 2, 5, 10, 20, 30, 40과 시드 42, 43으로 생성했다. 등록 영상은 원본을 사용했다. 강도 20, 30, 40에서 세 FVC DB의 증강 영상 1,440장을 새로 만들었고, 본 학습과 평가는 FVC2002와 FVC2004를 대상으로 했다.

DB마다 손가락 ID 5개를 개발에 사용하고 5개를 확인용으로 분리했다. 개발 ID를 순환 분할해 학습 3개와 검증 2개로 비교했다. 이후 선택된 설정을 개발 ID 전체로 다시 학습했다. 확인셋에서는 DB와 조건별로 본인 140쌍과 타인 640쌍을 비교했다. 원본 등록과 변형된 입력을 매칭하는 비교 방향을 고정했다.

사전학습 DeepPrint의 특징 추출부를 고정하고 마지막 투영을 rank 4로 미세조정했다. 개발 검증에서 minutiae 투영과 증강을 사용한 후보를 선택했다. 후보 재학습은 3 epoch이었다. 원본 EER과 변형 조건 평균 EER을 동등하게 반영한 개발 목적값은 6.06%에서 5.78%로 내려갔다. 비교 점수는 texture 22%, minutiae 78%로 고정했다.

원본과 σ=40은 C++ DLL 실측이다. 중간 강도는 저장한 임베딩에 같은 정합 수식을 적용한 결과다. 각 강도의 EER은 두 시드 평균이다. C++ DLL 검증 9,360쌍에서 등록·시도·비교 실패는 0건이었다. 캐시 기반 실험과 DLL 간 최대 점수 차이는 0.001이었다.

결론

FVC2002는 σ=30까지 대체로 개선됐으나 σ=40에서 두 시드의 변화 방향이 달랐다. 양방향 필터는 원본 EER을 7.09%에서 4.25%로 낮췄고, σ=40의 시드 42에서는 44.08%에서 46.03%로 올렸다. 원본과 강한 노이즈에 동일 필터를 적용하면 결과가 달라지는 점을 확인했다.

FVC2004의 σ=40 EER은 1.20%p 내려갔다. 같은 minutiae 투영을 원본만으로 학습한 비교군에서도 캐시 기반 σ=40 평균 EER은 17.71%로, 증강 학습의 17.78%와 비슷했다. FVC2002도 원본 학습군이 σ=40에서 43.81%를 기록해 이번 증강의 추가 이득은 확인하지 못했다.

FVC2004의 지문 영역 자르기는 원본 EER을 8.66%에서 4.41%로 낮췄고, ±10도 회전에서도 약 9.05~9.72%에서 4.41~4.56%로 낮췄다. 후보와 결합한 원본 EER은 4.05%였다. 영역 자르기는 원본과 회전 세 조건의 오프라인 실험이므로 강한 노이즈에서의 효과는 추가 평가가 필요하다.

개발 비교에서 FMR 1%를 목표로 선택한 후보 임계값 0.894를 적용하면, 표준 전처리의 FVC2004 확인셋 원본에서 FMR 8.44%, FNMR 10.00%였다. 후보는 build/finetune/finetune-noise40-20261124-175440/deepprint_texminu_512.onnx에 저장했다. 평가 앱은 기존 DLL과 ONNX를 사용한다.

기록

split.csv에는 개발·확인 손가락 ID, development_folds.csv에는 후보 선택 점수, preprocessing_development.csv에는 전처리 선택 근거, confirmation.csv에는 조건별 지표, native_validation.csv에는 C++ DLL과의 검증 결과가 있다. summary.json과 trained_projections.npz에 실험 설정 및 학습된 투영을 저장했다.
