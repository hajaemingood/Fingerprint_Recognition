DeepPrint 전처리 및 정합 가중치 비교
2026-11-26

배포본과 같은 ONNX를 고정하고 DB마다 원본 3,160쌍(본인 280, 타인 2,880)을 비교했다.
기존 손가락 ID 분할을 재사용했다. 개발과 확인은 DB별로 서로 다른 5개 ID에서 각각 본인 140쌍과 타인 640쌍을 사용했다.
개발 셋에서만 전처리와 공통 가중치를 선택했다. 전체 결과는 두 집합에 걸친 타인 쌍도 포함한다.

FVC2002 양방향 필터는 3×3, 공간 σ=1에서 밝기 차이 σ 6·12·20·30을 비교했다.
FVC2004는 전경 ROI의 0·5·10·15·20% 여백, 전체 프레임 중심 이동 및 ROI 10%의 bicubic 리사이즈를 비교했다.
FVC2000 입력은 표준 전처리를 사용했다. 질감 가중치 0~100%를 5% 간격으로 평가하고 기존 22%도 포함했다.
기준 전처리의 ONNX 실험 점수 9,480개는 기존 C++ DLL 기록과 모두 일치했다.

두 후보의 전처리는 FVC2002 bilateral-30, FVC2004 roi-20으로 같다.
FVC2002 bilateral-12와 bilateral-30은 배포 DLL의 KISA 함수에 필터링한 원본 픽셀을 입력해 각각 다시 검증했다.
σ=12의 전체/확인 EER은 6.48%/4.25%, σ=30은 6.71%/4.25%였다.
σ=30은 개발 EER 2.91%로 선택됐으며 σ=12의 개발 EER은 3.07%였다.
FVC2004 roi-20은 별도 C++ DLL을 빌드해 원본 3,160쌍에서 전체 4.78%, 확인 4.56%를 재현했다.
KISA 검증에서는 후보마다 원본 80장의 템플릿을 만들고 KISA_Compare를 3,160회 호출했다. 처리 실패는 없었다.

이 실험은 원본 TIFF로 전처리 효과를 측정했다. 증강 영상에서의 효과는 별도 검증 대상이다.
